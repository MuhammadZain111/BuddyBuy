# BuddyBuy
# 🛒 BuddyBuy – Modern E-Commerce Website | React.js + Tailwind CSS

A modern, responsive, and feature-rich **E-Commerce Web Application** built using **React.js**, **Tailwind CSS**, **Redux Toolkit**, and modern frontend development practices. BuddyBuy delivers a clean shopping experience with responsive layouts, product browsing, cart management, and an intuitive user interface.

## 🌐 Live Demo

**Live Website:** https://buddybuy.vercel.app/

---

# 📖 About the Project

BuddyBuy is a responsive e-commerce frontend designed to showcase modern web development techniques. The project focuses on delivering a fast, user-friendly shopping experience with reusable React components, state management using Redux Toolkit, and a clean UI built with Tailwind CSS.

This project is ideal for learning React architecture, frontend best practices, responsive design, and modern UI development.

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/buddybuy.git
```

### Navigate into the Project

```bash
cd buddybuy
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Visit:

```text
http://localhost:5173
```
